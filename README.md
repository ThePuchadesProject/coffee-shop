# Coffee Shop — Order & Tip Calculator

[English](#english) | [Español](#español)

---

## English

This is a practice project built with React, TypeScript, and TailwindCSS. It simulates a simple point-of-sale system for a coffee shop, where customers can select items from the menu, add them to their order, and calculate the total bill including tips.

Demo: [coffeeshop.thepuchadesproject.com](https://coffeeshop.thepuchadesproject.com)

### What the project does

- Shows a menu with different coffee and food options.
- Adds items to an order without creating duplicate lines (updates quantity instead).
- Shows an order summary with item prices, quantities, and a button to remove items.
- Tip calculator with different percentage options.
- Dynamic calculation of subtotal, tip amount, and final total to pay.
- Button to reset and clear the order once completed.
- Styled with TailwindCSS for a clean and responsive layout.

### Tech stack

- React 19
- TypeScript
- TailwindCSS
- Vite

### How to run it locally

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Español

Este es un proyecto de práctica desarrollado con React, TypeScript y TailwindCSS. Simula un sistema sencillo de gestión de pedidos para una cafetería, donde se pueden elegir productos del menú, añadirlos a la comanda y calcular el total de la cuenta incluyendo la propina.

Demo: [coffeeshop.thepuchadesproject.com](https://coffeeshop.thepuchadesproject.com)

### Qué hace el proyecto

- Muestra un menú con diferentes opciones de café y comida.
- Permite añadir productos a la orden evitando duplicados (actualiza la cantidad en su lugar).
- Muestra el resumen del pedido con precios individuales, cantidades y botón para eliminar productos.
- Selector de propinas con diferentes porcentajes.
- Cálculo automático de subtotal, importe de la propina y total a pagar.
- Botón para reiniciar y vaciar la orden una vez finalizado el pedido.
- Interfaz maquetada con TailwindCSS, limpia y adaptada a móviles.

### Tecnologías utilizadas

- React 19
- TypeScript
- TailwindCSS
- Vite
